## Working rules

**The version is already bumped.** `book.json` reads `0.7.3` as of this document, so
content edits land in an open version rather than triggering a bump each time. Do not
bump again inside this cycle.

**Do not run the build ritual per change.** EPUB, PDF variants, and the
`static/downloads/` swap happen once, at close, run by the synthesizer. See
`AUDITOR-BRIEF.md` section 5.

**Do not merge to main.** Main auto-deploys production and production runs live
Stripe keys. Merging is CT's call.

**Run the harness at both ends of any pass:**

```bash
python3 scripts/sts.py verify          # math, meta, precedents. Exits non-zero.
python3 scripts/sts.py verify --links  # add the network source check
python3 scripts/sts.py book            # current word counts. Trust this over any doc.
python3 scripts/sts.py id verify       # block index integrity after manual .md edits
```

A doc that asserts a version or a word count is a claim, not a measurement. Only
`book.json` and `sts.py` are authoritative. `AUDITOR-BRIEF.md` currently carries 15
stale version strings, which is exactly the failure that let a live pricing bug sit
unnoticed for ten days.
