  previous figure was rebuilt by eye against them. The layout is now measured, named, and

  ```bash
  python3 scripts/build_book_plate.py verify        # rebuild reference plates, diff them
  python3 scripts/build_book_plate.py build --sprite ... --out ... --title ... --caption ...
  ```

  negative-controlled — moving `TITLE_GAP` by two rows makes both plates fail on size and
  the command exit non-zero — so a pass means something.

  The constants it encodes, recovered from five agreeing plates: width 760; background
  `#020617`; 2px `#1e293b` rule inset 7px; art box top at y=44, max 640x480, integer
  NEAREST upscale only; title cap-top 24 rows under the sprite in Courier New Bold 30 at
  `#f59e0b`; caption ascender-top 38 rows under that in Courier New 19 at `#94a3b8`;
  canvas height = title cap-top + 114.

## Working rules

Unchanged from v0.7.4 except the version number. In particular:

**The version is already bumped.** `book.json` reads `0.7.5`. Content edits land in an
open version rather than triggering a bump each time. Do not bump again inside this cycle.

**Do not merge to main.** Main auto-deploys production and production runs live Stripe
keys. Merging is CT's call.

**This worktree carries dirty paths belonging to other sessions.** Stage by name. Never
`git add -A`. See `CLAUDE.md`.

**Run the harness at both ends of any pass:**

```bash
python3 scripts/sts.py verify          # math, meta, refs, precedents. Exits non-zero.
python3 scripts/sts.py verify --links  # add the network source check
python3 scripts/sts.py book            # current word counts. Trust this over any doc.
python3 scripts/sts.py id verify       # block index integrity after manual .md edits
python3 scripts/build_book_plate.py verify   # figure-plate layout, after any art pass
```

A doc that asserts a version or a word count is a claim, not a measurement. Only
`book.json` and `sts.py` are authoritative.
