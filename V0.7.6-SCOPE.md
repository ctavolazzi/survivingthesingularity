## Working rules

Unchanged from v0.7.5. In particular: the version is already bumped, do not bump
again inside this cycle; do not merge to main; this worktree carries dirty paths
belonging to other sessions, stage by name, never `git add -A`; run the harness at
both ends of any pass:

```bash
python3 scripts/sts.py verify          # math, meta, refs, precedents
python3 scripts/sts.py verify --links  # add the network source check
python3 scripts/sts.py book            # word counts. Trust this over any doc.
python3 scripts/sts.py id verify       # block index integrity after manual edits
python3 scripts/build_book_plate.py verify   # figure plates, after any art pass
```

A doc that asserts a version or a word count is a claim, not a measurement. Only
`book.json` and `sts.py` are authoritative.
