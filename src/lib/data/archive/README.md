# Archive extras: The Precedent File

The bonus file that came with the preorder while the book was a nonfiction
draft. It is here so `/archive` can show it: the offer told those buyers the
archive stays readable, and once the paid download became the novel, their old
download link no longer returns this file.

These two files are **build output, frozen**: `The-Precedent-File.md` and
`Sources-and-Citations.md` exactly as `scripts/build_bonus.py` produced them
for v0.11.0 (the Markdown is the same 51,682 bytes the delivered bundle's
manifest recorded). Do not edit them. The research they came from is
`manuscript/HISTORY-CASEBOOK.md`.
