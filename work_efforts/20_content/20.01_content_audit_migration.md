## Closeout (2026-08-02)

Closed as superseded. Never started, and the content architecture it was written
against has since been replaced by something with stronger guarantees.

The audit assumed content was scattered and needed reconciling. It is not. Book
text now has a single source of truth at `src/lib/data/book/`, one `.md` per
section, running order gated by `book.json`. The site, EPUB, PDFs and
`manuscript/` snapshots are all generated outputs. That rule is documented in
`README.md` and enforced by tooling, which removes the drift this audit was
meant to catch by hand.

Each task area is now covered by a standing mechanism rather than a one-off pass:

| Original task area | Now covered by |
| --- | --- |
| Blog post rendering, metadata, routing | `sts.py audit`, 0 errors across 35 pages and 18 API routes |
| Book chapter loading, TOC, cross-references | `book.json` gate plus `sts.py book` |
| Broken internal links, unsourced claims | `sts.py factcheck` and the public `/factcheck` trace, see `FACTCHECK.md` |
| Image display across devices | `image_build_hook.js` plus `tests/e2e/d-device-compliance.spec.js` |
| Mobile reading experience | `tests/e2e/e-mobile-design.spec.js` |
| Accessibility compliance | `tests/e2e/h-usability.spec.js` |
| Cross-browser testing | `.github/workflows/e2e-webkit.yml` |

Two listed areas no longer exist as surfaces. There is no newsletter archive to
audit, and the three dependency work efforts it named (20.03, 20.04, 40.02) were
either never created or are being closed in this same pass.
