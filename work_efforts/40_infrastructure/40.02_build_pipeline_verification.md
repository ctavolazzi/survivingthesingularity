## Closeout (2026-08-02)

Closed as superseded. Never started as a manual pass, because the pipeline
acquired automated gates that do the same job continuously.

The build now runs four checks before Vite is even invoked. `prebuild` is
`check-offer-drift` then `check-book-downloads` then `check-resolver-parity`
then `image_build_hook.js`, so a drifted offer, a missing book download or a
resolver mismatch fails the build rather than shipping.

| Original task | Now covered by |
| --- | --- |
| Test full production build | `.github/workflows/build-guard.yml`, guards that the committed tree builds |
| Verify image optimization end to end | `image_build_hook.js` in `prebuild`, now content-hash cached |
| Check static assets processed | `sts.py audit`, sitemap ghosts 0, unlisted 0 |
| Validate prebuild hooks | the three `check:*` scripts, each independently runnable |
| Deployment adapter compatibility | `sts.py live` plus `static/_redirects` |

Build performance, listed as a success criterion at under 2 minutes, was
addressed independently. A build cache was added to `image_build_hook.js` on
2026-08-02 that skips sharp re-encoding when the source hash, encoder config and
output files all match. Per the note in that file the image step previously
accounted for roughly 45s of a 46s prebuild.

**One caveat this work effort correctly anticipated.** It lists
`image_build_hook.js` under "Build Components to Verify". That script still lives
inside `work_efforts/`, which is now a retired tracker. It is production code in
an archive directory. Relocating it to `scripts/` is an open follow-up recorded
in the closeout README.
